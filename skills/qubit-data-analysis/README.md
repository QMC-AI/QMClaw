# qubit-data-analysis

量子比特实验数据分析 Skill。

## 内容

- SKILL.md：完整的数据分析指导
- README.md：本文件

## 包含内容

1. 数据获取方式（loadDataset, get_data）
2. fitData 参数提取（IQraw, T1, XEB 等）
3. 质量判定标准（Pass/Fail 阈值）
4. 绘图方法（headless 模式关键）
5. sciplot 科研绘图

## 使用方式

当用户要求分析实验数据、处理测控结果、绘制图表时使用此 Skill。

## 相关资源

- MCP服务：`workspace/analysis_mcp_server.py`
- 科研绘图：`sciplot-academic` 库
